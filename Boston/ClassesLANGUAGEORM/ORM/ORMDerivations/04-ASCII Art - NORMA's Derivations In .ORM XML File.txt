Derivation interpretation note
------------------------------
A NORMA derivation is best understood as a small query AST.

- Fact Type Readings behave like joins expressed in natural language.
- RootObjectType and SubPath.RootObjectType introduce variable scopes / aliases.
- PathedRoles define traversal steps across Fact Types.
- ObjectUnifiers declare that different path occurrences denote the same logical object.
- CalculatedValues define intermediate expressions.
- Conditions filter the bound tuples, including CalculatedCondition refs.
- DerivationProjections map internal bindings back to the roles of the derived Fact Type.

So, conceptually, a derivation is much closer to:
    FROM / JOIN / WHERE / projected outputs
than to flat prose.

That is why renderer correctness depends on preserving the derivation AST,
not merely storing DerivationText.
